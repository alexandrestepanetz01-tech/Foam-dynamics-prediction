# Foam Dynamics Prediction

This repository contains the Python code used for the research paper *Predicting Plasticity in Two-Dimensional Foam Channel Flow Around an Obstacle*.

This work was carried out by Alexandre Stepanetz, Bahaa Mazloum, Benjamin Dollet, and Misaki Ozawa at the LIPhy laboratory in Grenoble, France.

The goal of this project is to predict the future dynamics of a dense, amorphous system of simulated particles using machine-learning techniques.

The dataset is available on Zenodo:

[Download the dataset from Zenodo](https://zenodo.org/records/21774620)

## Environment

The code was developed using Python 3.

The following Python standard-library modules are used:

* `time`
* `os`
* `pathlib`
* `math`
* `multiprocessing`

The following external packages are also required:

* `tqdm`
* `numpy`
* `matplotlib`
* `scikit-learn`
* `scipy`

The `mpl_toolkits` package is included with Matplotlib.

The external dependencies can be installed using:

```bash
pip install tqdm numpy matplotlib scikit-learn scipy
```

## Data Format

Download the dataset using the Zenodo link above.

The data are stored in text files. Each file begins with a header containing:

* the number of particles;
* the width of the simulation box;
* the height of the simulation box.

The remainder of each file contains data for 900 particles across 1,000 independent configurations. Each row contains five values:

1. the particle's x-coordinate;
2. the particle's y-coordinate;
3. the particle size;
4. the neighbor rearrangement target;
5. the non affine displacement target.

Each file corresponds to a different timescale of interest, (\Delta t):

* 50
* 100
* 200
* 300
* 600
* 900
* 1,200
* 1,500

## `Processing_data`

This directory contains two Python scripts.

## `Structural_Descriptors.py`

This script computes the structural descriptors of the particles for each configuration.

It is the most computationally expensive part of the workflow. Processing a single data file can take several hours when using 10 CPU cores.

## `Corse_Graining.py`

This script coarse-grains the Behler–Parrinello descriptors. It must therefore be applied to the output files generated by `Structural_Descriptors.py`.

## `Prediction_Models`

This directory contains three similar scripts corresponding to the three models evaluated in the paper:

* linear regression;
* logistic regression;
* a neural network.

After processing the data, these scripts can be used to train the models and generate predictions.

The outputs include model scores and visualizations with color bars.

## `Plot_Figures`

This directory contains the results and the code required to reproduce the figures presented in the paper.
